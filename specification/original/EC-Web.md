# 映画業界向けECサイト Webシステム 顧客向け要件定義

## 1\. 対象システム概要

### システム名

映画業界向けECサイト Webシステム

### 顧客向け機能の目的

一般ユーザーおよび会員ユーザーが、映画作品を検索・閲覧し、映画関連商品や映画チケットをオンラインで購入できるようにする。

### 対象アクター

*[Table view](https://miro.com/app/board/uXjVGoqMd4g=/?moveToWidget=3458764675968236796&cot=14)*

| アクター | 説明 |
| --- | --- |
| ゲストユーザー | 未ログイン利用者。映画・商品閲覧、会員登録、ログインが可能 |
| 会員ユーザー | ログイン済み利用者。商品購入、チケット購入、購入履歴確認が可能 |

## 4\. UC\-01 会員登録する

### 4\.1 概要

ゲストユーザーが、映画関連商品やチケットを購入するために会員アカウントを作成する。

### 4\.2 事前条件

*[Table view](https://miro.com/app/board/uXjVGoqMd4g=/?moveToWidget=3458764675968236809&cot=14)*

| ID | 条件 |
| --- | --- |
| PRE\-UC01\-001 | ユーザーが未ログインである。 |
| PRE\-UC01\-002 | 会員登録画面にアクセスできる。 |

### 4\.3 機能要件

*[Table view](https://miro.com/app/board/uXjVGoqMd4g=/?moveToWidget=3458764675968236819&cot=14)*

| 要件ID | 要件 |
| --- | --- |
| FR\-UC01\-001 | システムは、会員登録画面を表示できる。 |
| FR\-UC01\-002 | ユーザーは、氏名、メールアドレス、パスワード、パスワード確認を入力できる。 |
| FR\-UC01\-003 | システムは、入力されたメールアドレスが既に登録済みか確認する。 |
| FR\-UC01\-004 | システムは、入力内容が妥当な場合、会員情報を登録する。 |
| FR\-UC01\-005 | システムは、会員登録完了後、登録完了画面を表示する。 |
| FR\-UC01\-006 | システムは、登録完了後にユーザーを自動ログイン状態にしてもよい。 |
| FR\-UC01\-007 | システムは、登録日時を会員情報として記録する。 |

### 4\.4 入力項目

*[Table view](https://miro.com/app/board/uXjVGoqMd4g=/?moveToWidget=3458764675968236859&cot=14)*

| 項目 | 必須 | 入力条件 |
| --- | --- | --- |
| 氏名 | 必須 | 1〜50文字 |
| メールアドレス | 必須 | メールアドレス形式、最大255文字、一意 |
| パスワード | 必須 | 8〜64文字、英字・数字を含む |
| パスワード確認 | 必須 | パスワードと一致すること |

| ルールID | ルール |
| --- | --- |
| BR\-UC01\-001 | 同一メールアドレスで複数会員を登録できない。 |
| BR\-UC01\-002 | パスワードは平文で保存してはならない。 |
| BR\-UC01\-003 | 退会済みメールアドレスの再利用可否は、システム設定に従う。初期仕様では再利用不可とする。 |

### 4\.6 受入条件

*[Table view](https://miro.com/app/board/uXjVGoqMd4g=/?moveToWidget=3458764675968236868&cot=14)*

| 受入条件ID | 条件 |
| --- | --- |
| AC\-UC01\-001 | 未登録のメールアドレスと妥当な入力内容で会員登録できる。 |
| AC\-UC01\-002 | 登録済みメールアドレスを入力した場合、登録できずエラーが表示される。 |
| AC\-UC01\-003 | パスワードとパスワード確認が一致しない場合、登録できない。 |
| AC\-UC01\-004 | 登録完了後、登録完了画面が表示される。 |

## 19\. 研究用に特に重要な要件

*[Table view](https://miro.com/app/board/uXjVGoqMd4g=/?moveToWidget=3458764675968287272&cot=14)*

| 重要観点 | 関連要件 |
| --- | --- |
| 認証・認可 | 他人のカート・購入履歴を見られない |
| 在庫整合性 | カート投入時ではなく注文確定時に在庫減算する |
| 価格保持 | 購入履歴は注文時点の価格を保持する |
| 販売期間 | 販売期間外の商品は購入不可 |
| 残席管理 | チケット購入時に残席数を減算する |
| 模擬決済 | 外部決済連携は行わず、成功扱いにする |
| スコープ制御 | 座席指定やクーポンは初期対象外にする |

特に、**在庫減算タイミング、購入履歴の価格保持、他ユーザー情報へのアクセス制御**は、設計判断としてADR化しやすく、後続の保守シナリオでも影響範囲分析の題材にしやすい。
