# 要件定義書 — 映画館ECウェブシステム

バージョン: 1.0  
作成日: 2026-07-15  
作成: 01-requirements Agent

---

## 1. 用語集

| 用語 | 定義 |
|------|------|
| ゲストユーザー | 未ログインの利用者。映画/商品の閲覧、会員登録、ログインが可能。 |
| 会員ユーザー | ログイン済みの利用者。注文、チケット購入、購入履歴確認が可能。 |
| 商品注文 | 物販商品の購入処理。カートを経由して確定する。 |
| チケット購入 | 上映回を選択して映画チケットを購入する処理。 |
| 購入履歴 | 商品注文履歴とチケット購入履歴の総称。 |
| 販売期間外 | 商品または上映回が購入対象期間外の状態。 |
| スナップショット | 注文確定時点の価格・商品名・数量・割引情報を不変保持したデータ。 |
| 残席数 | 上映回ごとに管理される購入可能席数。座席指定は行わない。 |
| 模擬決済 | 本番決済APIとは連携せず常に成功として扱う決済処理。 |

---

## 2. 背景

映画作品の閲覧から映画関連商品の購入、映画チケット購入までを一貫して提供する顧客向けWebシステムが必要である。現状は機能が分散し、ユーザー体験と業務データ管理の一貫性が不足している。

---

## 3. 目的

一般ユーザーおよび会員ユーザーが、映画作品を検索・閲覧し、映画関連商品や映画チケットをオンラインで購入できるようにする。

---

## 4. 対象ユーザー（ペルソナ）

| ユーザー種別 | 利用できる機能 |
|---|---|
| ゲストユーザー | 映画・商品の閲覧、会員登録、ログイン |
| 会員ユーザー | 上記に加えて商品購入、チケット購入、購入履歴確認 |

## 6. 成功条件（Acceptance Criteria）

| ID | 条件 | 計測方法 |
|---|---|---|
| AC-COM-001 | 未登録ユーザーが会員登録できる | 登録完了画面へ遷移する |
| AC-COM-002 | 登録済みユーザーがログインできる | ログイン後にセッションが付与される |
| AC-COM-003 | 会員ユーザーが商品を検索・カート追加・注文確定できる | 注文番号が発行される |
| AC-COM-004 | 会員ユーザーが映画チケットを購入できる | 購入番号が発行され残席が減算される |
| AC-COM-005 | 会員ユーザーが自分の購入履歴を確認できる | 本人の注文/チケット履歴のみ表示される |
| AC-COM-006 | 入力不備・在庫不足・権限不足・認証失敗・販売期間外の5分類で期待するエラーメッセージと遷移先が一致する | 各エラー分類のテストケースが全通過 |

## 7. 業務フロー / ユーザーストーリー

**ゲストユーザー**
- As a ゲストユーザー
- I want 映画作品と商品を検索し、必要に応じて会員登録/ログインしたい
- So that 映画関連商品とチケットをスムーズに購入できる

**会員ユーザー**
- As a 会員ユーザー
- I want カート編集、注文確定、チケット購入、履歴確認を行いたい
- So that 購入体験を一つのサービス内で完結できる

## 8. 共通機能要件

| ID | 要件 |
|---|---|
| C-UI-001 | 各画面にヘッダー、検索導線、ログイン状態表示、カート導線を表示する |
| C-UI-002 | 入力エラー時、該当項目近傍にエラーメッセージを表示する |
| C-UI-003 | 一覧画面に検索条件、結果件数、ページングを表示する |
| C-UI-004 | 金額は税込・3桁区切り円表記で表示する（例: 1,980円） |
| C-UI-005 | 日時は YYYY/MM/DD HH:mm 形式で表示する |
| C-DATA-001 | 削除済み/非公開の商品・映画作品は顧客向け画面に表示しない |
| C-DATA-002 | 販売開始前/販売終了後の商品は閲覧可能でも購入不可とする |
| C-DATA-003 | 在庫0の商品は購入不可かつ「在庫なし」と表示する |
| C-DATA-004 | 注文確定時点の価格・商品名・数量・割引情報を保持する（スナップショット） |

---

## 9. 認証・認可

| ID | 要件 |
|---|---|
| C-AUTH-001 | ゲストは映画検索、映画詳細閲覧、商品検索、商品詳細閲覧、会員登録、ログインを利用できる |
| C-AUTH-002 | 会員は上記に加えてカート、注文、チケット購入、購入履歴確認を利用できる |
| C-AUTH-003 | ログイン必須機能へ未ログインでアクセスした場合はログイン画面へ遷移する |
| C-AUTH-004 | 会員は自分自身のカート、注文、チケット、購入履歴のみ参照できる |

---

## 10. エラー仕様（共通）

| ID | 条件 | 挙動 |
|---|---|---|
| ERR-001 | 必須入力不足・形式不正 | 項目単位でエラーメッセージを表示 |
| ERR-002 | 認証失敗 | メールアドレス存在有無を推測できない汎用メッセージを表示 |
| ERR-003 | 在庫不足 | 注文/購入/カート追加を失敗させ理由を表示 |
| ERR-004 | 販売期間外・非公開・権限不足 | 操作不可とし適切に遷移または通知 |
| ERR-005 | 注文/チケット購入の更新失敗 | 不整合データを残さない（ロールバック） |

## 11. 非機能要件（NFR）

### パフォーマンス

| ID | 要件 |
|---|---|
| NFR-PERF-001 | 映画検索、商品検索、購入履歴一覧は通常時3秒以内に初期表示 |
| NFR-PERF-002 | カート追加、カート更新、注文確定、チケット購入確定は通常時5秒以内に応答 |
| NFR-PERF-003 | 一覧画面はページングし、1ページ20件を標準とする |

### セキュリティ

| ID | 要件 |
|---|---|
| NFR-SEC-001 | パスワードはハッシュ化保存 |
| NFR-SEC-002 | 要認証機能への未認証アクセスを許可しない |
| NFR-SEC-003 | 他会員データの参照・変更を禁止 |
| NFR-SEC-004 | 入力値はサーバー側で検証 |
| NFR-SEC-005 | SQLインジェクション、XSSを防止 |
| NFR-SEC-006 | 認証失敗時にアカウント存在可否を推測可能にしない |

### 整合性・可用性

| ID | 要件 |
|---|---|
| NFR-AVL-001 | 注文登録と在庫減算の整合性を保つ |
| NFR-AVL-002 | チケット購入登録と残席減算の整合性を保つ |
| NFR-AVL-003 | 注文確定失敗時に不完全注文を残さない |
| NFR-AVL-004 | チケット購入失敗時に不完全購入を残さない |

### ユーザビリティ

| ID | 要件 |
|---|---|
| NFR-USAB-001 | トップ画面から主要機能へ遷移可能 |
| NFR-USAB-002 | 入力エラー時に修正項目と理由を理解可能 |
| NFR-USAB-003 | 注文確定前に配送先・支払・金額を確認可能 |
| NFR-USAB-004 | チケット確定前に映画名・上映日時・券種・枚数・金額を確認可能 |

## 13. 機能要件（FR）

### FR-001: 会員登録

| 項目 | 内容 |
|---|---|
| 機能目的 | 購買機能利用のための会員アカウント作成 |
| 機能概要 | 氏名、メールアドレス、パスワード入力で会員登録を行う |
| ユーザーストーリー | ゲストとして、購入機能を使うために会員登録したい |
| 入力項目 | 氏名(1-50文字)、メールアドレス(形式/255文字以内/一意)、パスワード(8-64文字英数字)、確認用パスワード(一致必須) |
| バリデーション | 必須/形式/一致/重複メール不可 |
| エラー条件 | 既登録メール、形式不正、確認用パスワード不一致 |
| 完了条件 | 登録完了画面表示、必要に応じ自動ログイン |
| 関連NFR | NFR-SEC-001, NFR-SEC-006 |

### FR-002: ログイン

| 項目 | 内容 |
|---|---|
| 機能目的 | 会員機能利用のための認証 |
| 機能概要 | メールアドレスとパスワードでログインする |
| ユーザーストーリー | 会員として、購入処理に進むためにログインしたい |
| 入力項目 | メールアドレス、パスワード |
| バリデーション | 必須/形式 |
| エラー条件 | 認証失敗時は汎用メッセージを表示（存在有無を推測させない） |
| 完了条件 | ログイン状態となりトップまたは遷移元に戻る |
| 関連NFR | NFR-SEC-001, NFR-SEC-006 |

### FR-003: 映画作品検索

| 項目 | 内容 |
|---|---|
| 機能目的 | 関心映画を探索する |
| 機能概要 | タイトル・ジャンル・公開状況で検索、並び替え可能 |
| ユーザーストーリー | ユーザーとして、見たい映画を素早く見つけたい |
| 入力項目 | タイトルキーワード(任意)、ジャンル(任意)、公開状況(任意)、並び順(任意) |
| バリデーション | 任意入力、公開対象のみ表示 |
| エラー条件 | 0件時は0件メッセージ表示 |
| 完了条件 | 一覧表示から詳細画面へ遷移可能。20件/ページのページング |
| 関連要件 | C-DATA-001, NFR-PERF-001, NFR-PERF-003 |

### FR-004: 映画作品詳細閲覧

| 項目 | 内容 |
|---|---|
| 機能目的 | 作品情報と購買導線の確認 |
| 機能概要 | 映画詳細、関連商品、上映スケジュールを表示 |
| ユーザーストーリー | ユーザーとして、作品情報を確認して購入判断したい |
| 表示項目 | タイトル、あらすじ、ジャンル、公開日、上映時間、関連商品一覧、上映回一覧 |
| 制約条件 | 上映終了回は購入導線を表示しない |
| 完了条件 | 商品詳細遷移可能、会員はチケット購入導線を利用可 |
| 関連要件 | C-DATA-001, C-AUTH-002 |

### FR-005: 商品検索・閲覧

| 項目 | 内容 |
|---|---|
| 機能目的 | 商品発見と購入判断 |
| 機能概要 | キーワード/カテゴリ/関連映画で検索し、商品詳細を表示 |
| ユーザーストーリー | ユーザーとして、欲しい映画関連商品を見つけたい |
| 入力項目 | 商品名キーワード(任意)、カテゴリ(任意)、関連映画(任意)、在庫ありのみフィルタ(任意) |
| バリデーション | 非公開/販売期間外/在庫なし制御（C-DATA-001〜003） |
| 完了条件 | 会員はカート追加へ進める。20件/ページのページング |
| 関連要件 | C-DATA-001, C-DATA-002, C-DATA-003, NFR-PERF-001 |

### FR-006: 商品をカートに追加

| 項目 | 内容 |
|---|---|
| 機能目的 | 商品購入候補を保持 |
| 機能概要 | 商品詳細から数量指定でカート追加、同一商品は数量加算 |
| ユーザーストーリー | 会員として、複数商品をまとめて購入準備したい |
| 入力項目 | 数量(1以上、在庫数以下) |
| バリデーション | 販売可否確認、在庫超過不可、ログイン状態確認 |
| 業務ルール | カート投入時は在庫減算しない。注文確定時に減算する |
| 完了条件 | 追加完了表示、ヘッダーのカート件数更新 |
| 関連要件 | C-AUTH-002, C-DATA-002, C-DATA-003 |

### FR-007: カート内容変更

| 項目 | 内容 |
|---|---|
| 機能目的 | 注文前の内容調整 |
| 機能概要 | 数量変更、削除、合計再計算、注文導線表示 |
| ユーザーストーリー | 会員として、注文前に数量を調整したい |
| バリデーション | 在庫超過不可、数量0は削除扱い |
| エラー条件 | 注文不可商品がカートに存在する場合は注文手続き不可 |
| 完了条件 | 変更後の小計・合計が再計算される |
| 関連要件 | C-DATA-002, C-DATA-003 |

### FR-008: 商品注文

| 項目 | 内容 |
|---|---|
| 機能目的 | 商品購入を確定 |
| 機能概要 | 配送先/支払方法入力 → 確認 → 注文確定 → 在庫減算 → 注文番号発行 |
| ユーザーストーリー | 会員として、希望商品を配送先指定で注文確定したい |
| 入力項目 | 氏名、郵便番号、都道府県、市区町村・番地、電話番号、支払方法 |
| バリデーション | 必須/形式/最新在庫確認（確定直前に再チェック） |
| データ構造 | 注文ヘッダ(Order)と明細(OrderItem)に購入時スナップショットを保持 |
| 完了条件 | 注文完了画面と注文番号表示、カートクリア |
| 関連NFR | NFR-AVL-001, NFR-AVL-003, NFR-PERF-002, NFR-USAB-003 |

### FR-009: 映画チケット購入

| 項目 | 内容 |
|---|---|
| 機能目的 | 上映回の座席枠確保と購入確定 |
| 機能概要 | 上映回・券種・枚数選択で購入確定し、残席減算と購入番号発行 |
| ユーザーストーリー | 会員として、希望上映回のチケットを購入したい |
| 入力項目 | 上映回、券種、枚数、支払方法(模擬) |
| バリデーション | 販売期間内確認、上映開始前確認、残席数確認 |
| 制約条件 | 座席指定は対象外（残席数管理のみ） |
| 完了条件 | 購入完了画面表示、購入履歴に反映 |
| 関連NFR | NFR-AVL-002, NFR-AVL-004, NFR-PERF-002, NFR-USAB-004 |

### FR-010: 購入履歴確認

| 項目 | 内容 |
|---|---|
| 機能目的 | 過去購入の確認 |
| 機能概要 | 商品注文履歴とチケット履歴を本人分のみ一覧/詳細表示 |
| ユーザーストーリー | 会員として、過去の注文内容を確認したい |
| バリデーション | 本人アクセス制御（他会員の履歴は参照不可） |
| データ構造 | 購入時点スナップショットを表示（OrderItem/TicketPurchaseItem） |
| 完了条件 | 注文日/購入日降順で履歴を確認可能 |
| 関連要件 | C-AUTH-004, NFR-SEC-003, NFR-PERF-001 |

## 14. 制約条件

| ID | 制約 |
|---|---|
| CON-001 | 本システムは研究用サンプルであり、外部決済サービスとの実連携を行わない |
| CON-002 | 決済処理は常に成功する模擬決済として扱う |
| CON-003 | 商品配送処理は管理者側の注文ステータス更新まで（配送会社API連携なし） |
| CON-004 | チケット購入は座席指定を行わず、上映回ごとの残席数のみ管理 |
| CON-005 | 商品レビュー、ポイント、クーポン、レコメンドは初期スコープ外 |
| CON-006 | 多言語対応は初期スコープ外（日本語のみ） |

## 15. Open Questions

|---|---|---|

| OQ-005 | パスワードハッシュアルゴリズムの指定（bcrypt等）は設計フェーズで確定が必要 | 中 |
